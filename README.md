# 340万分の1 — 1 in 3.4 Million

偶然の境遇から生まれた会社を見守り、必要な局面で判断するブラウザゲーム。採用、取引、資金繰り、事件、世代交代が積み重なり、一社の歴史になります。

移行元は「会社の一生」0.9.12。ゲーム内表記と保存形式は互換性を保つため現行版を維持しています。

## 遊びの流れ

- 月単位で自動進行。重要な相談では停止し、自分で判断できます。
- 手動・おまかせを切り替え、困りごとには自分から介入できます。
- 社長が交代しても同じ会社の経営と歴史が続きます。固定年数で終了しません。
- 日誌は通常表示で直近5年、振り返りでは全期間を表示します。

## 開発

Node.js 22以上。外部パッケージのインストール・ビルドは不要です。

```sh
npm start
# http://127.0.0.1:4173

npm test
```

別ポートは `PORT=8080 npm start`（PowerShellでは先に `$env:PORT=8080`）。テストはモデル・保存復元・タイマー・DOMスタブによる操作確認です。実ブラウザの描画やスマートフォンの操作を保証するものではありません。

## 構成

| パス | 内容 |
| --- | --- |
| `dist/` | 配信するソース一式。生成物ではなく直接編集する静的アプリ |
| `dist/model.js` | 会計、乱数、人物・顧客・契約、事件、世代交代 |
| `dist/app.js` / `dist/style.css` | UI・進行・表示 |
| `dist/evidence.js` / `dist/model-data.json` | 実測・推計・仮定と出典・適用条件 |
| `dist/assets/` | 専用生成した事務所画像 |
| `dist/legacy/` / `dist/legacy-v02/` | 旧セーブを扱う旧版。現行から参照されるため保持 |
| `tests/` | Node.js標準テストランナーによる自動テスト |
| `scripts/validate-*.mjs` | 採用・事件・長期世代交代のモデル検算 |
| `docs/development-history.md` | 移行前の要件・改修履歴。旧仕様も含む |
| `dist/requirements.html` | 現行設計と検証範囲 |

`dist/cohort.json` と `scripts/generate-cohort.mjs` は旧規則の比較用です。現行の統計として流用しません。モデルの確率や会計を変更するときは、出典・仮定・保存互換・再現性を併せて確認します。

## 統計と名前

名称は中小企業庁が公表した、2021年6月時点の企業数約337.5万者を約340万に丸めたものです。対象は民営・非一次産業の企業（会社と個人事業者）で、法人会社だけの数や現在の企業数を表しているわけではありません。

- [中小企業・小規模事業者の数（2021年6月時点）](https://www.chusho.meti.go.jp/koukai/chousa/chu_kigyocnt/2023/231213chukigyocnt.html)

実際の統計、期間換算などの推計、ゲーム設計上の仮定を区別しています。会社の寿命や選択の効果を実証した予測モデルではありません。名称の分母は、特定の会社が生成される確率や希少性を意味しません。

## リスペクト・素材

[80億分の1 / 1 in 8 Billion](https://1in8b.life/ja/) へのリスペクトから制作しました。統計に基づく境遇から時間が流れ、必要な場面に介入する体験と、`1in8b` という命名構造を参考にしています。公式作品・提携作品ではありません。

事務所画像 `dist/assets/studio.png` は、このプロジェクト向けに画像生成で制作した素材です。生成時のプロンプトは開発履歴に残しています。統計の原資料の権利は各提供元に帰属します。

## 保存と公開

セーブ・速度・操作設定はブラウザのlocalStorageに保存します。サーバーへ送信しません。公開URLが変わると旧URLのセーブは自動では引き継がれません。現時点でセーブのエクスポート／インポートUIはありません。

任意の静的ホスティングで `dist/` の中身を公開できます。GitHub Actionsはテストのみで、自動デプロイしません。元の[公開サイト](https://company-life-oct17.ivgtr.chatgpt.site)は移行時点の0.9.12のままです。このリポジトリからの変更は自動反映されません。
