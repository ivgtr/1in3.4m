# 340万分の1 — 1 in 3.4 Million

偶然の境遇から生まれた会社を見守り、必要な局面で判断するブラウザゲーム。採用、取引、資金繰り、事件、世代交代が積み重なり、一社の歴史になります。

## 遊びの流れ

- 月単位で自動進行。重要な相談では停止し、自分で判断できます。
- おまかせの選択予定を表示し、相談に触れると一時停止します。
- 軽い見送りは一度で返答。費用や経営に関わる判断は選択後に確定します。
- 社長が交代しても経営と歴史は続きます。固定年数で終了しません。
- 日誌は通常表示で直近5年、全日誌と振り返りでは全期間を表示します。

## 開発

Node.js 24.15以上（24系LTSを推奨）。

```sh
npm ci
npm start
# http://127.0.0.1:4173

npm test
npm run build
npm run preview
```

React + Vite + TanStack Routerの静的SPAです。Routerはゲーム・全日誌・遊び方の画面遷移を担当します。シミュレーションはブラウザ内で完結し、サーバーやQuery層はありません。ハッシュルーティングと相対アセットURLを使うため、ルートでもサブディレクトリでも配信でき、SPA用のサーバー書き換えは不要です。

### 検証

`npm test`はNode標準テストランナーで既存の会計・再現性・世代交代等を検算し、React操作はTesting Library + jsdomで4ケースだけを確認します。タイマーは既存のPlaybackテストを再利用しています。

今回の環境ではChromiumの起動がOSサンドボックスでブロックされ、実ブラウザのPC/スマートフォン描画確認は未実施です。公開前にダイアログのスクロール・フッター、キーボード操作、スマートフォン幅を実機で確認してください。

追加の統計モデル検算は `node scripts/validate-generations.mjs` などで実行できます。出力先は `validation/` で、アプリの設定やビルド成果物を変更しません。

## 保存

セーブ・速度・操作設定はブラウザのlocalStorageに保存し、サーバーへ送信しません。再読み込み時は停止状態から再開します。現行の `company-life-save-v3`・世代交代対応済みの保存形式（life.version 2）は同じキーのまま読み込みます。記録の書き出し・別会社の保存も利用できます。

古い形式への切り替えや復旧用フォールバックはありません。対応しない形式や読み込み失敗はエラーを表示し、保存データを変更しません。URLが変わると旧URLのセーブは自動では引き継がれません。インポートUIはありません。

## 統計と名前

名称は中小企業庁が公表した2021年6月時点の企業数約337.5万者を約340万に丸めたものです。民営・非一次産業の会社と個人事業者を含み、法人会社だけの数や現在の企業数を表すものではありません。

- [中小企業・小規模事業者の数（2021年6月時点）](https://www.chusho.meti.go.jp/koukai/chousa/chu_kigyocnt/2023/231213chukigyocnt.html)

実際の統計、期間換算などの推計、ゲーム設計上の仮定を区別しています。会社の寿命や選択の効果を実証した予測モデルではありません。名称の分母は、特定の会社の生成確率や希少性を意味しません。
