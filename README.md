# 340万分の1 — 1 in 3.4 Million

偶然の境遇から生まれた会社を見守り、必要な局面で判断するブラウザゲーム。売上や資産の最大化だけでなく、採用・取引・資金繰り・世代交代がつながる一社の歴史を楽しみます。

月単位で時間が進み、相談には自分で判断するか、おまかせで返答します。自動判断の予定を表示し、相談に触れると一時停止します。社長が交代しても経営と歴史は続き、年数だけで会社が終了することはありません。

## 起動

Node.js 24.15.0以上が必要です。

```sh
npm ci
npm start
# http://127.0.0.1:4173
```

## 開発

React + Vite + TanStack Routerの静的SPAで、シミュレーションはブラウザ内で完結します。実装・保守の方針は [AGENTS.md](AGENTS.md)、コマンドの定義は [package.json](package.json) を参照してください。

| 場所 | 責務 |
| --- | --- |
| `src/main.jsx` / `src/App.jsx` / `src/pages/` | 起動と画面遷移・構成 |
| `src/domain/` | ゲームのルール・計算・乱数・出典 |
| `src/game/` | 共有状態・保存・操作・進行制御 |
| `src/components/` | 表示・入力・共通UI |

スタイルはCSS Modulesを使い、共通の表示は `src/components/shared.module.css`、全体設定は `src/global.css`、変数は `src/tokens.css` に置きます。CSS間の `@value` 参照は使いません。レイヤー順は `base → shared → components` とし、遅延読み込みでも順序が変わらないよう [index.html](index.html) で宣言しています。

保存のない開始画面・遊び方では計算モデルを読み込まず、ゲーム開始・保存会社の読み込み時に起動します。画面単位の遅延読み込みを維持し、容量と不要な依存の混入をビルドで検査します。検査対象・上限は [scripts/bundle-budget.mjs](scripts/bundle-budget.mjs) が正本です。

### 検証

| コマンド | 用途 |
| --- | --- |
| `npm test` | モデル・React操作・容量検査の回帰テスト |
| `npm run build` | `dist/` の生成と容量・依存関係の検査 |
| `npm run test:browser` | ビルド済みの配信物をChromiumで操作確認 |
| `npm run preview` | ビルド済みの配信物をローカルで確認 |

ブラウザテストは先にビルドし、初回は `npx playwright install chromium --only-shell` を実行してください。テスト用サーバーは4180番を使い、失敗時のtraceとスクリーンショットは `test-results/` に出力します。CIはテスト・ビルド・ブラウザテストを実行します。

追加の統計・長期進行の検算は `scripts/validate-*.mjs`（例：`node scripts/validate-generations.mjs`）で実行し、結果を `validation/` に出力します。

## 保存と進行

- 会社・速度・操作設定はブラウザのlocalStorageに保存し、サーバーへ送信しません。別会社の保存と記録の書き出しができますが、インポートUIはありません。
- 別のブラウザやオリジン（プロトコル・ホスト・ポート）へ保存は自動で引き継がれません。再読み込み後は停止状態になります。
- 読み込みに失敗した場合はエラーを表示し、既存の保存を維持します。初期状態への置き換え、旧形式への切り替え、自動再試行はしません。
- 必要な画面の読み込み中は進行を止め、すべての読み込みが完了するまで自動進行を再開しません。画面表示の失敗も停止と通知で知らせ、ゲームを開けない失敗は専用画面で扱います。
- 日誌の「最新へ戻る」は閲覧位置だけを戻し、時間を再開しません。閲覧中に相談も保留している場合は「相談に戻る」を案内します。

### 通知

- 操作結果・失敗は最新1件を表示し、同じ種別・本文の通知は重複させません。表示中のエラーは通常通知で上書きしません。
- 通常画面では右下（狭い画面では下部）、相談・メニューでは最前面のヘッダー直下に表示し、本文のスクロールに追従させません。
- 閉じるまで保持し、エラー時は自動進行を停止します。閉じるだけでは再開しません。通知履歴・永続化・自動消去・外部配信は設けません。

## 統計・クレジット

名称は[中小企業庁が公表した2021年6月時点の企業数](https://www.chusho.meti.go.jp/koukai/chousa/chu_kigyocnt/2023/231213chukigyocnt.html)約337.5万者を丸めたものです。民営・非一次産業の会社と個人事業者を含み、現在の企業数や会社の生成確率を示すものではありません。

実測・推計・ゲーム設計上の仮定を区別しており、会社の寿命や選択の効果を実証した予測モデルではありません。出典・対象・適用限界は [evidence.js](src/domain/evidence.js)、[insights.js](src/domain/insights.js)、モデル設定は [model-data.json](src/domain/model-data.json) を参照してください。

[80億分の1 / 1 in 8 Billion](https://1in8b.life/ja/)の体験と命名構造を参考に制作しました。公式作品・提携作品ではありません。`public/assets/studio.png` は本作向けのAI生成画像です。統計資料の権利は各提供元に帰属します。

## 公開

`npm run build` で生成した `dist/` の中身を静的ホスティングへ配置します。ハッシュルーティングと相対URLを使うため、サブディレクトリでも配信でき、SPA用のサーバー書き換えは不要です。GitHub Actionsは検証のみで、自動デプロイはしません。
